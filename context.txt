Step 2: Contest Data Source

Do not scrape LeetCode and Codeforces directly.

Use CLIST API.

CLIST aggregates:

LeetCode
Codeforces
CodeChef
AtCoder
TopCoder
HackerEarth
HackerRank

and many more.

Official website:

CLIST.by

Get:

CLIENT_ID
API_KEY

API example:

import requests

url = "https://clist.by/api/v4/contest/"

params = {
    "upcoming": "true",
    "format": "json"
}

headers = {
    "Authorization":
    f"ApiKey YOUR_USERNAME:YOUR_API_KEY"
}

response = requests.get(url, headers=headers, params=params)

print(response.json())

Step 6: Telegram Commands
/start
async def start(update, context):
    await update.message.reply_text(
        "Welcome to Contest Tracker 🚀"
    )
/upcoming
async def upcoming(update, context):
    contests = get_upcoming_contests()

    msg = ""

    for c in contests[:10]:
        msg += (
            f"{c['name']}\n"
            f"{c['platform']}\n"
            f"{c['start']}\n"
            f"{c['url']}\n\n"
        )

    await update.message.reply_text(msg)
