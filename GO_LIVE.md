**Q: What if bot doesn't respond?**
A: Wait 30 seconds, check Railway logs for "Reminder scheduler started"

**Q: What if /upcoming shows no contests?**
A: Subscribe first (/subscribe Codeforces), then /upcoming again

**Q: How do I monitor the bot?**
A: Railway dashboard → Logs tab → See real-time output

**Q: What if something breaks after deployment?**
A: Check logs, use TESTING_GUIDE.md troubleshooting section

**Q: Can I update the bot later?**
